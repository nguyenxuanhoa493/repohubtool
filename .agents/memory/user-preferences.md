# User Preferences

- **Ngôn ngữ giao tiếp:** Luôn luôn trả lời người dùng bằng tiếng Việt (`luôn trả lời bằng tiếng việt`). Code comments và commit message có thể dùng tiếng Anh hoặc tiếng Việt không dấu theo convention có sẵn.
- **Quy trình phát hành:** Mặc định khi được yêu cầu phát hành thì chỉ phát hành OTA (cập nhật qua mạng trong app). Chỉ đóng gói bản full zip và tạo GitHub Release khi người dùng yêu cầu rõ ràng ("phát hành bản full").
- **Thiết bị cầm tay test:** TrimUI Smart Pro / Brick (IP thường gặp: `192.168.100.115`, `172.16.3.102`). Không tự tiện reboot hoặc kill process mà người dùng không yêu cầu.
