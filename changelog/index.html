    • Files already on the card are renamed when the app opens; saves, per-game settings and box art are renamed with them.
  • 1.432026-08-30

    A device still on the old Java emulator is upgraded automatically

    • An in-app update carries the app only, not the 66 MB emulator, so a device could sit on the old one indefinitely with nothing saying so. Now the app notices and upgrades it at startup, keeping saves.
  • 1.422026-08-30

    Reinstalling the Java emulator no longer wipes saves

    • J2ME saves and per-game settings live inside the emulator folder, and reinstalling replaced that folder wholesale. They are now moved aside and put back — including when the install fails halfway.
