Changelog

Every release note since 1.32 — the same sentence the update screen on your device showed when the build arrived.

  • 1.502026-08-31Latest

    Official NextUI support, dual artwork saving, and cleaner utilities menu

    • Packaged as a native Tool Pak (Tools/tg5040/RetroHub.pak & Tools/tg5050/) with full in-app Wi-Fi auto-updates.
    • ROM directories with NextUI tags like Game Boy Advance (GBA) are resolved automatically, and artwork is saved into .media/ beside stock Imgs/.
    • Java J2ME installation now sets up JAVA.pak for NextUI as well as Emus/JAVA for Stock OS.
    • Fixed encrypted zip entry edge-case in Java jars refusing to launch.
    • Removed the redundant 'Reload ROMs' button from Utilities since NextUI scans games automatically.
  • 1.492026-08-30

    Java games at 320x240 no longer land in the 240320 folder

  • 1.482026-08-30

    Two pinned Java shelves and 130 more Gameloft titles

  • 1.472026-08-30

    Added giaitri321.vip Java source, prioritizing 320x240 versions

  • 1.462026-08-30

    Java emulator updates seamlessly via the in-app updater

  • 1.452026-08-30

    Text input in Java games is now supported

  • 1.442026-08-30

    Java games with a space in the filename now open

    • The emulator opens a jar through a "jar:file:" URI it never escapes, so one space and it could not read the manifest — the game died before drawing a frame. 758 of the 3,357 Java sources in the library are named that way.
    • Files already on the card are renamed when the app opens; saves, per-game settings and box art are renamed with them.
  • 1.432026-08-30

    A device still on the old Java emulator is upgraded automatically

    • An in-app update carries the app only, not the 66 MB emulator, so a device could sit on the old one indefinitely with nothing saying so. Now the app notices and upgrades it at startup, keeping saves.
  • 1.422026-08-30

    Reinstalling the Java emulator no longer wipes saves

    • J2ME saves and per-game settings live inside the emulator folder, and reinstalling replaced that folder wholesale. They are now moved aside and put back — including when the install fails halfway.
  • 1.412026-08-30

    New FreeJ2ME build for the Brick Pro

    • Three display modes — PIXEL, SMOOTH, HQ — switchable in the app or with START + R3 in game.
    • Pad layouts H, K and X cycle on the device with START + SELECT, and quitting a game now asks first.
