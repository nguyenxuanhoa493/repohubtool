Changelog

Every release and what it changed, newest first. Each headline is the note that version actually shipped with — the same sentence the app shows on its update screen.

  • 1.442026-08-30Latest

    Java games with a space in the filename now open

    • The emulator opens a jar through a "jar:file:" URI it never escapes, so one space and it could not read the manifest — the game died before drawing a frame. 758 of the 3,357 Java sources in the library are named that way.
    • Files already on the card are renamed when the app opens; saves, per-game settings and box art are renamed with them.
  • 1.432026-08-30

    A device still on the old Java emulator is upgraded automatically

    • An in-app update carries the app only, not the 66 MB emulator, so a device could sit on the old one indefinitely with nothing saying so. Now the app notices and upgrades it at startup, keeping saves.
  • 1.422026-08-30

    Reinstalling the Java emulator no longer wipes saves

    • J2ME saves and per-game settings live inside the emulator folder, and reinstalling replaced that folder wholesale. They are now moved aside and put back — including when the install fails halfway.
  • 1.412026-08-30

    New FreeJ2ME build for the Brick Pro

    • Three display modes — PIXEL, SMOOTH, HQ — switchable in the app or with START + R3 in game.
    • Pad layouts H, K and X cycle on the device with START + SELECT, and quitting a game now asks first.
  • 1.402026-08-29

    Vietnamese text no longer shows as boxes on font-poor themes

  • 1.392026-08-29

    The game library updates in place, no reinstall

  • 1.382026-08-29

    No more placeholder box art; games without a cover show a name-and-system tile

  • 1.372026-08-29

    Alphabet jump lands on the right game, with no column drift

  • 1.362026-08-29

    The game list no longer stops at 1,000 entries

  • 1.352026-08-29

    Games launch with the emulator and mode the device has selected

  • 1.342026-08-29

    Extracted games keep their proper name; the file is named on screen

  • 1.332026-08-29

    Downloads in .rar/.7z now extract to a real ROM

  • 1.322026-08-29

    Owned games open play/delete, not the download prompt

Builds before 1.32 predate the update screen's "what changed" line, so they are not listed here rather than described after the fact. Full notes and the download for each release are on GitHub.
